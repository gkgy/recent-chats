# 最近对话

一个用于浏览本机 Codex 最近聊天的实验性插件。页面按最近活动排序，支持搜索聊天标题或项目文件夹，最多显示 200 条未归档的本机 Codex 聊天。搜索范围不包含聊天正文。

## 当前状态

- MCP 服务、读取本机聊天索引及时间排序已在开发机器上做过基础检查。
- 侧边栏入口的固定、页面内搜索以及点击后跳转聊天尚未完成端到端验证，当前版本可能无法在所有 Codex 版本中使用。
- 目前依赖 macOS、Python 3、`~/.codex/state_5.sqlite` 的现有结构和 `codex://threads/` 链接；这些内部细节可能随 Codex 更新而变化。
- 默认只读本机聊天索引；点击聊天时请求系统打开对应的 Codex 链接。不包括远程设备或 ChatGPT 的聊天。

## 文件

- `.codex-plugin/plugin.json`：插件描述。
- `.mcp.json`：本地 MCP 服务配置。
- `server/`：本地服务与页面。
- `skills/`：聊天内查找入口的技能说明。

这是正在开发中的个人项目，尚未作为完整安装包验证。请先检查代码和本机数据权限，再自行测试。
